# Отдельный поддомен biblioteka.med-local.ru

Этот пакет — самостоятельный сайт, полностью изолированный от основного репозитория
med-local. Публикация статей и любые другие правки на основном сайте больше не смогут
случайно удалить документы и код Библиотеки.

## Что внутри

```
index.html            — главная (и единственная) страница сайта
biblioteka.css         — стили
biblioteka.js          — вся логика (поиск, фильтры, попап, форма)
biblioteka-data.json    — данные всех 252 документов
files/                  — все PDF, разложены по 8 категориям
```

## Шаг 1. Создать новый репозиторий на GitHub

1. Зайди на github.com → нажми **+** в правом верхнем углу → **New repository**
2. Имя репозитория: например `med-local-biblioteka`
3. Public
4. **НЕ** ставь галочку "Add a README file" (пусть будет полностью пустой)
5. **Create repository**

## Шаг 2. Загрузить файлы через GitHub Desktop

1. Открой GitHub Desktop → **File → Clone repository...**
2. Найди только что созданный `gmtossoriamkt/med-local-biblioteka` → **Clone**
3. **Show in Explorer** — откроется пустая папка
4. Скопируй в неё **всё содержимое** этого архива (index.html, biblioteka.css,
   biblioteka.js, biblioteka-data.json, папку files) — не саму папку архива,
   а именно файлы и папку files из неё
5. В GitHub Desktop появится список новых файлов → впиши сообщение коммита
   ("Первая публикация библиотеки") → **Commit to main** → **Push origin**

## Шаг 3. Создать проект на Vercel

1. Зайди на vercel.com → **Add New → Project**
2. Найди в списке репозиторий `med-local-biblioteka` → **Import**
3. Framework Preset можно оставить "Other", ничего не меняя → **Deploy**
4. Подожди, пока задеплоится (1-2 минуты)

## Шаг 4. Привязать поддомен

1. В новом проекте на Vercel → **Settings → Domains**
2. Впиши `biblioteka.med-local.ru` → **Add**
3. Vercel покажет, какую DNS-запись нужно добавить — обычно это:
   ```
   Тип: CNAME
   Имя: biblioteka
   Значение: cname.vercel-dns.com
   ```
   (Точное значение возьми с экрана Vercel — может немного отличаться)

## Шаг 5. Добавить DNS-запись в Timeweb

1. Зайди на timeweb.cloud → **Домены и SSL** → `med-local.ru` → вкладка **DNS**
2. **Добавить запись**
3. Тип: **CNAME**, Имя/поддомен: **biblioteka**, Значение: то, что показал Vercel
4. Сохранить

Подожди 10-30 минут, пока DNS обновится, и в Vercel рядом с доменом появится
"Valid Configuration".

## Шаг 6. Проверить

Открой `biblioteka.med-local.ru` — должен открыться раздел со списком документов,
формой и поиском, полностью независимо от основного сайта.

## Шаг 7. Добавить ссылку в меню основного сайта (необязательно, но желательно)

На основном сайте (`med-local.ru`, репозиторий `med-local`) замени ссылку в меню
с `/biblioteka/` на `https://biblioteka.med-local.ru/` (полный адрес, а не
относительный путь, потому что теперь это другой сайт).

⚠️ Эта конкретная правка может снова затираться при публикации статей —
но это уже мелочь: сама библиотека при этом продолжит работать, просто временно
не будет видна прямая ссылка в меню.
